# Flower Shop by SAE

A responsive, single-page flower shop website built with **HTML5, CSS3, JavaScript, Bootstrap Icons, and Google Fonts**. The project focuses on a clean floral aesthetic, responsive layouts, smooth navigation, service presentation, customer testimonials, and contact information.

## ✨ Features

* Full-screen hero/banner section
* Responsive navigation menu
* Smooth scrolling between sections
* Feature highlights
* Flower service showcase with hover animations
* Customer testimonials section
* Contact and opening-hours section
* Social media icons using Bootstrap Icons
* Responsive design for desktop and mobile devices
* Google Fonts integration
* CSS hover and transition effects

## 🛠️ Technologies

* **HTML5** — Page structure and content
* **CSS3** — Styling, responsive layout, animations, and visual effects
* **JavaScript** — Navigation menu interaction and smooth scrolling
* **Bootstrap Icons** — Interface and social icons
* **Google Fonts** — Dosis and Playwrite AR typography

## 🚀 Run Locally

No installation or backend server is required.

1. Download or clone this repository.
2. Make sure the `images` folder is in the same directory as `index.html`.
3. Open `index.html` in a web browser.

For a better development experience, open the project using **Visual Studio Code** with the **Live Server** extension.

## 🌐 Deployment

This is a static website, so it can be deployed easily using platforms such as **GitHub Pages, Netlify, or Vercel**.

For GitHub Pages:

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and the `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save the settings.
7. GitHub will generate a public URL for the website.

## 📱 Responsive Design

The layout adapts to smaller screens using CSS media queries. The feature, service, testimonial, and footer sections reorganize automatically for mobile devices.
